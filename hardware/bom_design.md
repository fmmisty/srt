# RFD USB-AES 2CH ― 回路ブロック & 部品確定(BOM案)

1U 完結型 **SRT音声コーデック**。USBオーディオ・フロントエンド(XMOS UAC2)＋**Raspberry Pi 4 を内蔵**し、SRT一式(`srt_send`/`srt_recv`/`codec_web.py`)を搭載。1台で送受信が完結する。
※「バランスアナログ＋AES/EBU＋ドライバ不要USB」を1台で満たすPi向け既製品は無い → 本機で埋める。

## 0. 構成の確定(2026-09)

- **Pi 内蔵**：本機の中に Raspberry Pi 4 を収め、内部USBでフロントエンドと接続。→ **背面に LAN(RJ-45) を追加**、**+5V(Pi)レール必須**、Wi-Fi(Pi内蔵、金属筐体なら外部アンテナ)。
- **全二重(双方向)**：内蔵Piで `srt_send`(自局音声→SRT送出) と `srt_recv`(SRT受信→自局音声出力) を**同時起動**。フロントエンドはADC/AES-in(入力)とDAC/AES-out(出力)を両方持つので、**1台で送りも受けも同時**にできる。2台を向き合わせれば双方向通話。
- **操作**：コーデック切替は携帯WEB(`codec_web.py`)、SRT ON/OFF・latency も同様(自社版=ライセンス無し)。
- 背面I/O(更新): AC IN │ **LAN** │ USB-C(保守) │ AES IN/OUT │ ANALOG IN/OUT L/R （＋Wi-Fiアンテナ）　※**REMOTE/GPIOは無し(不採用)**

AES/EBU IN(XLR110Ω)─[パルストランス]─[AES RX/ASRC]────────┤ I2S     ┌──内蔵Pi 4──┐   │

AES/EBU OUT(XLR110Ω)←[パルストランス]←[AES TX]────────────┘         │codec_web│   │

                                           └────────────────────────────────────┘
  全二重: 入力(ADC/AES-in)→srt_send→SRT送出 / SRT受信→srt_recv→出力(DAC/AES-out) を同時

| ブロック | 採用/推奨チップ | 備考 |
|---|---|---|
| USB/UAC2 コントローラ | **XMOS XU316-1024-FB265** (xcore.ai) | USB2.0 HS内蔵、UAC2、I2S/SPDIF/ASRC対応。ドライバ不要 |
| ADC(アナログ入力) | **TI PCM1862** (2ch, PGA/I2C内蔵) | 24bit/最大96k+。ラインIN向け |
| DAC(アナログ出力) | **TI PCM5242** (2ch) | 24bit/差動出力。THAT1646へ |
| 入力ラインレシーバ | **THAT1246** or **INA1620/OPA1612** + 抵抗 | バランス受け+アンチエイリアスLPF。+4dBu/+20dBu max |
| 出力ラインドライバ | **THAT1646** | バランス送り。放送レベル。仕様書通り |
| **AES/EBU 送受(要確定)** | **★ TI SRC4392** (第一候補) | AES3 RX+TX+**デュアルASRC**を1チップ。クロック非同期問題を同時解決 |
| ↑ 代替(ディスクリート) | AES RX **AK4113**／AES TX **AK4104**／(必要なら)ASRC **AK4137 or SRC4382** | 3チップ構成。SRC4392が使えれば不要 |
| AESトランス | Scientific Conversion / Pulse の110Ω AES3パルストランス ×IN/OUT | XLR-F(IN)/XLR-M(OUT)、AES3-1992 |
| クロック | 低ジッタ XO **24.576MHz** & **22.5792MHz**(または1個+分周)、必要ならVCXO | ローカルマスタ。SRC4392でAES-inは吸収 |

## 2. 電源レール(案)

AC-IN(100–240V) → 内部AC-DCモジュール → 各レールを生成。

| レール | 用途 | 生成 | 目安 |
|---|---|---|---|
| +12V(または+5V) 主 | 各DC-DC入力 | 医療/産業向けAC-DCモジュール(15–25W) | ~15W |
| **+5V(必須)** | **内蔵Pi 4 給電**/USB/ロジック | Buck(余裕を持って) | **Pi4は最大~3A → 5V/4A以上を確保** |
| +3.3V(デジタル) | XU316 I/O・ロジック・OLED | Buck/LDO | |
| +0.9V(XU316コア) | xcore.ai VDD | 専用Buck(低リップル) | XU316データシート値に合わせ確定 |
| **アナログ+3.3V(クリーン)** | PCM1862/PCM5242 のAVDD | 専用LDO(低ノイズ) | ADC/DAC音質の要 |
| **±15V(確定)** | THAT1646/入力レシーバ(THAT1246) | DC-DC(絶縁 or 昇圧)＋LDO | 差動出力~+21〜22dBu → +20dBu max を確保 |

- **クロック用**は別LDOで電源分離(ジッタ低減)。
- アナログGNDとデジタルGNDは1点接続(スター)。**接地は御社 電源基板方式(/PE分離・シャーシGND)に準拠**。
- **Pi 内蔵で確定** → +5V(Pi)必須、消費も +10〜15W上乗せ(AC-DCモジュールは 25〜35W級を見る)。放熱(ファン/ヒートシンク)も考慮。
- **レベル設計(確定)**: 公称 **+4dBu**／最大 **~+22dBu(±15V)** ＝ ヘッドルーム約18dB。割り当ては **0dBFS ≒ +22dBu**(+4dBu=−18dBFS)。放送標準で十分、±18Vは不要。
